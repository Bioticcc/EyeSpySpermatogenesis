Statistics

Exact = same stage as the paper; within one = same or neighbouring stage (XII next to I). Balanced = mean of the per-stage recalls, so rare stages count equally. Paper stages are unchecked transcriptions.

Model history

Scores are leave-one-section-out: every tubule is staged by a model that never saw its section. "Paper sections" scores every version on the same tubules (Yeongseok's paper sheets), so versions compare like for like. Δ: 95% interval of the difference in exact accuracy, in percentage points (section bootstrap). Smoothed models use the same classifier as their parent, with neighbour smoothing at prediction time (opt-in, never the default). The full history with every setting is Model_Checkpoints/registry.json.
